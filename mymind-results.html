02 / INFERENCE COST
每题耗时、tokens 与工具调用
从每题首次贪心轨迹重算，包含正常失败，按全部题目取算术平均。以下是本地策略推理消耗，不是训练输出长度或 API 计费 tokens。

      
模型 / 每题首次轨迹平均延迟
秒 / 题		平均输入
tokens / 题		平均输出
tokens / 题		输入 + 输出
tokens / 题		平均工具调用
search / 题

      

      
如何读这些开销延迟为历史任务墙钟时间，包含生成、真实检索与轨迹内处理；模型装载在计时外。运行时点、GPU/服务负载和输出长度均未受控，不能据此断言某种训练目标使推理更快。

      
计时、token 累计与工具调用的精确定义
平均延迟
对原始 elapsed_s 求均值：模型装载后，从题目预算预留开始，到轨迹结束；包含轨迹内进度写入，不含最终评分及最终记录写入。不是在线服务并发压测延迟。
平均 tokens 消耗
逐题累加所有模型调用的 input_tokens 与 output_tokens。每轮重复输入的历史会重复计数，输入包含工具观察；输出包括检索动作和最终结构化结果。共享Qwen tokenizer，合计表示模型处理量，不是唯一上下文长度。
平均工具调用
逐题统计 trajectory.searches 长度，即实际原子 search 次数；一次搜索通常触发Embedding与重排服务。该指标不等于HTTP请求数。
样本与费用边界
全部统计组基础设施失败为0，正常失败仍保留；每题均有2次模型生成。未把远程Embedding/重排的异源token计入本地策略合计。远程API实际账单不能由此换算。

单seed、固定合成政策，最终120题与训练/开发划分不同。未证明稳定提升、真实客服效果或未知政策泛化。原最终测试没有用于更换checkpoint。
配置对照的边界
B为后补的单seed实验，沿用既有开发集；历史A参照含服务升级差异，无新的120题盲测。不以某个单参数解释整体差异。
奖励与成功率
训练平均奖励含部分得分和负分，不能当作成功率；完整成功按原v13规则判断。严重错误率越低越好，与协议失败可能重叠。
