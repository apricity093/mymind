# 固定路由下训练单一客服策略

模块、训练协议与独立推理入口见[策略架构与运行](../agentic_rl_architecture.md)。本文说明固定路由、训练共享策略的理由与影响。

在约两个工作周的交付窗口内，MyMind 首版 Agentic RL 固定已有路由，训练一个客服策略负责证据获取与终止处置。联合训练路由器和多个专家会同时改变决策边界、轨迹数据与效果归因；单策略范围更适合完成真实多轮工具训练和 Base、SFT、RL 对照。

该决定允许复用现有多 Agent 应用，但实验结果只支持被训练策略的结论，不能解释为多 Agent 联合强化学习。更改这一边界时，需要重新设计任务、训练轨迹及对照。

账单和技术任务同时纳入同一策略的训练分布。角色标签由数据或既有应用路由提供，策略学习各角色接到任务之后的动作；两域分别评价，避免总体结果掩盖单域退化。
